# Fit Tool v1.8 · 网页版

[English](README.md) | **中文说明**

在浏览器里画路线、拖结点、调路线偏移，**本地生成** Garmin FIT 跑步数据。不需要后端，不需要安装任何东西。

**在线使用：** <https://eric-thy.github.io/fit-tool-web/>

## 能做什么

在地图上规划跑步路线（比如校园操场环线），导出一份包含距离、配速、心率、步频、步幅、触地时间、垂直振幅等数据的 FIT 活动文件——和手表记录出来的格式一致。

## 功能

### 路线编辑

- **点击添加结点**：在地图上点几个点，自动连成路线。
- **撤回 / 重做**：`Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`）。加结点、拖结点、整条平移、清除轨迹、切换地图源、导入路线都可以撤回，最多保留 80 步。
- **拖动任意结点**：按住橙色圆点拖动，折线与总距离实时更新；坐标会自动夹到合法范围，不会产生坏数据。
- **整条路线平移**：按住路线线条拖动即可整体移动，松手不会误加结点。
- **自定义起跑段 / 收尾段**：主路线是一整圈；「起跑段」是从起点（比如操场外）斜插到跑道上的开放连接线，「收尾段」是从跑道离开到终点（比如操场门口）的开放连接线。实际轨迹 = 起跑段 → 主路线 × 圈数 → 收尾段，所以起点终点不在一起也很自然。两段可以分别开关；线性模式下不使用。
- **保存 / 导入路线**：导出为 GeoJSON（主路线 + 可选的起跑段/收尾段、路线模式、圈数、偏移量）；导入支持 GeoJSON（`Feature` / `FeatureCollection` / `LineString` / `MultiLineString` / `Polygon`）、旧版 `{points:[{lat,lng}]}` 以及纯 `[[lng,lat],...]` 坐标数组。文件不合法时只提示错误，不会破坏当前路线。

### 数据生成

- **路线偏移可调**：0 ~ 12 米。`0` 表示轨迹完全贴合绘制路线；数值越大越像真实 GPS 的漂移。偏移沿路线连续变化、每圈首尾闭合，多圈叠起来是一条自然窄带，而不是几条互相错开的路线。
- **环形 / 线性模式**：环形自动闭合、可设置重复圈数。
- **生理参数**：静息心率、最大心率、体重、目标配速；一次最多导出 10 份不同开始时间与配速的文件。
- **预览**：在地图上播放轨迹，并把整条生成轨迹画出来，先看效果再导出。
- **完整跑步数据**：距离、配速、心率、步频、步幅、触地时间、垂直振幅、垂直步幅比、累计步数。
- **纯前端**：所有计算都在浏览器里完成，不上传任何数据。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 撤回 | `Ctrl+Z` / `Cmd+Z` |
| 重做 | `Ctrl+Y` 或 `Ctrl+Shift+Z` |

在输入框里按快捷键不会影响路线，仍然是输入框自己的撤销。

## 本地打开

直接双击 `index.html` 也能用（Leaflet 与生成逻辑都在本目录里），或者起一个静态服务器：

```bash
python -m http.server 8080
# 打开 http://localhost:8080
```

## 部署到 GitHub Pages

仓库根目录就是站点根目录：

1. 把本目录内容推到 `main` 分支。
2. 仓库 **Settings → Pages**，Source 选择 **Deploy from a branch**，分支 `main`、目录 `/ (root)`。
3. 访问 `https://<用户名>.github.io/<仓库名>/`。

`.nojekyll` 已包含，避免 Pages 用 Jekyll 处理静态资源。

## 目录结构

```
index.html        页面
main.js           地图交互、结点拖动、撤回栈、导入导出、生成流程
style.css         样式
fit-core.js       浏览器端 FIT 生成核心（@garmin/fitsdk + 活动数据模拟）
leaflet/          Leaflet 1.9.4（本地化，不依赖 CDN）
```

## 桌面版

另外还有一个 Windows 桌面版（`fit-tool.exe`），它把同一份页面跑在本地，并通过本地 Node 进程生成 FIT。两个版本共用同一份 `main.js`，只是生成后端不同，产出的 FIT 文件逐字节一致。

## 说明

- 地图源可选天地图 / OpenStreetMap / Google / 腾讯，国内源可能需要自备 Key（只存在浏览器 localStorage 里）。
- FIT 文件使用 Garmin 官方 `@garmin/fitsdk` 编码。
- 生成的数据仅供个人测试 / 学习使用，请遵守所在学校与平台的相关规定。
