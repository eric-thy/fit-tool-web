# Fit Tool v2.0 · 网页版

[English](README.md) | **中文说明**

在浏览器里画路线、改首尾圈、拖结点、调路线偏移，**本地生成** Garmin FIT 跑步数据。不需要后端，不需要安装任何东西。

**在线使用：** <https://eric-thy.github.io/fit-tool-web/>

## 能做什么

在地图上规划跑步路线（比如操场环线），需要的话单独改第一圈和最后一圈，然后导出一份包含距离、配速、心率、步频、步幅、触地时间、垂直振幅等数据的 FIT 活动文件。

## 路线编辑

- **点击添加结点**：自动连成路线。
- **撤回 / 重做**：`Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`），最多 80 步；加结点、拖结点、剪切、插点、平移、清除、导入都能撤回。
- **拖动结点**：折线与总距离实时更新，坐标自动夹在合法范围。
- **插入结点**：双击线段中间。
- **删除结点**：先点选（变橙），按 `Delete` 或点「删除结点」。
- **剪切两点间**：删掉两个结点之间较短的一段，闭合的环会被打开成开放路径。
- **整体平移**：按住线条拖动。
- **首圈 / 尾圈**：主路线是整圈；首圈替换第 1 圈、尾圈替换最后一圈。点「从主路线复制」拿到形状 →「剪切两点间」开个口 → 拖两端改形状（比如从场外斜插进跑道）→ 用「起点换到另一端」决定哪头是起点（尾圈是终点）。
- **保存 / 导入路线**：导出 GeoJSON（`FeatureCollection`，含 `main` / `start` / `end` 三段），导入支持 GeoJSON、旧版 `{points:[...]}`、纯 `[[lng,lat],...]` 数组；文件不合法只提示，不破坏当前路线。

## 圈数与接缝

- **圈数 = 总圈数**：4 圈 = 首圈 + 主路线 × 2 + 尾圈；某段没启用就用主路线顶上。
- 只有 1 圈时优先用首圈（其次尾圈，最后主路线）。
- 生成时主路线会**自动旋转到最靠近接点的顶点**，接缝处不会再拉出一条横穿操场的直线。

## 预览

- 进入预览后编辑路线和结点隐藏：**只画跑过的路段**，没跑到的地方不渲染。
- 颜色按本次跑步的速度范围：**慢=红，中=橙，快=绿**。
- **预览时长** 3～60 秒（默认 15 秒）：整段轨迹用多少秒播完，标签显示当前倍速；播放中拖动滑块立即生效。
- 消息栏显示进度：`42%（9.10 / 21.55 km）`。
- 点底部「退出预览」或按 `Esc` 回到编辑。

## 数据生成

- **路线偏移量** 0～12 米：轨迹相对绘制路线的摆动幅度，0 = 完全贴合。
- 环形 / 线性模式、静息心率、最大心率、体重、最多 10 份不同开始时间与配速的导出。
- 完整跑步数据：距离、配速、心率、步频、步幅、触地时间、垂直振幅、垂直步幅比、累计步数。
- 全部在浏览器本地计算，不上传任何数据。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 撤回 | `Ctrl+Z` / `Cmd+Z` |
| 重做 | `Ctrl+Y` / `Ctrl+Shift+Z` |
| 删除选中结点 | `Delete` |
| 退出预览 | `Esc` |

## 本地打开

直接双击 `index.html` 也能用（Leaflet 与生成逻辑都在本目录里），或起一个静态服务器：

```bash
python -m http.server 8080
# 打开 http://localhost:8080
```

## 部署到 GitHub Pages

仓库根目录就是站点根目录：

1. 把本目录内容推到 `main` 分支。
2. 仓库 **Settings → Pages**，Source 选 **Deploy from a branch**，分支 `main`、目录 `/ (root)`。
3. 访问 `https://<用户名>.github.io/<仓库名>/`。

`.nojekyll` 已包含。

## 桌面版

另外有一个 Windows 桌面版（`fit-tool.exe`），跑同一份页面，通过本地 Node 进程生成 FIT。两个版本共用同一份 `main.js`，只是生成后端不同，产出的 FIT 文件逐字节一致。

## 说明

- 地图源：天地图 / OpenStreetMap / Google / 腾讯；国内源可能需要自备 Key（只存在浏览器 localStorage）。
- 坐标纠偏（GCJ-02 ↔ WGS-84）同时作用于生成的文件和预览绘制。
- FIT 文件使用 Garmin 官方 `@garmin/fitsdk` 编码。
- 生成的数据仅供个人测试 / 学习使用，请遵守所在学校与平台的相关规定。
