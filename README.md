# Fit Tool v1.5 · 网页版

在线使用：<https://eric-thy.github.io/fit-tool-web/>

在浏览器里画路线、调路线偏移，**本地生成** Garmin FIT 跑步数据。不需要后端，不需要安装任何东西。

打开网页即可使用：地图上点几个点画出路线 → 设置圈数 / 配速 / 时间 → 拖动「路线偏移量」→ 预览 → 生成 FIT 文件。

## 功能

- **路线偏移可调**：0 ~ 12 米。0 表示轨迹完全贴合绘制的路线；数值越大越接近真实 GPS 的"漂"。
  偏移是沿路线连续变化的平滑抖动，多圈叠在一起是一条自然的窄带，而不是几条互相错开的路线。
- **多圈与线性模式**：环形路线自动闭合、可设置重复圈数；线性模式单程不闭合。
- **完整跑步数据**：距离、配速、心率、步频、步幅、触地时间、垂直振幅、垂直步幅比、累计步数等。
- **多份导出**：一次可生成最多 10 个不同开始时间 / 配速的 FIT 文件。
- **预览**：在地图上播放轨迹，并把整条生成轨迹画出来，先看效果再导出。
- **纯前端**：所有计算都在你的浏览器里完成，不上传任何数据；页面本身是静态文件。

## 本地打开

直接双击 `index.html` 也能用（Leaflet 与生成逻辑都在本目录里）。
如果浏览器限制本地文件，可在目录里起一个静态服务器：

```bash
python -m http.server 8080
# 打开 http://localhost:8080
```

## 部署到 GitHub Pages

仓库根目录就是站点根目录：

1. 把本目录内容推到仓库（默认分支 `main`）。
2. 仓库 **Settings → Pages**，Source 选择 **Deploy from a branch**，分支 `main`、目录 `/ (root)`，保存。
3. 等待一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`。

`.nojekyll` 已包含，避免 Pages 用 Jekyll 处理静态资源。

## 目录结构

```
index.html        页面
main.js           地图交互、路线绘制、导出流程
style.css         样式
fit-core.js       浏览器端 FIT 生成核心（@garmin/fitsdk + 活动数据模拟）
leaflet/          Leaflet 1.9.4（本地化，不依赖 CDN）
```

## 说明

- 地图源可选天地图 / OSM / Google / 腾讯，国内源可能需要自备 Key（页面内可填，保存在浏览器本地）。
- FIT 文件使用 Garmin 官方 `@garmin/fitsdk` 编码，与桌面版生成的字段完全一致。
- 生成的数据仅供个人测试 / 学习使用，请遵守所在学校与平台的相关规定。
